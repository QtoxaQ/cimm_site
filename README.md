# cimm_site
Сайт для заполнения конфигураций хранилища

Данный сайт позволяет управлять списком реакций в памяти роботизированной установки:
1) Редактировать SMILES реакции
2) Указывать соотношение реагентов, катализаторов и продуктов
3) Задавать температуру проведения реакции и время нагрева
4) Задавать целевое значение выхода продукта (в молях)

Реакции хранятся в формате json в соответствующем файле.

Разработано для: НИЛ "Интеллектуальная химическая робототехника" (КФУ, Химический институт им. А.М. Бутлерова)
